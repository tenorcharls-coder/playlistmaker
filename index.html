🎧 재생목록 메이커

곡 목록을 붙여넣으면 내 유튜브 계정에 재생목록을 만들어줘요

처음 한 번만: 구글 설정
  1. console.cloud.google.com 에서 새 프로젝트 만들기
  2. API 및 서비스 → 라이브러리 → YouTube Data API v3 사용 설정
  3. OAuth 동의 화면 → 외부(External) → 앱 이름 아무거나 → 테스트 사용자에 내 구글 계정 추가
  4. 사용자 인증 정보 → 만들기 → OAuth 클라이언트 ID → 유형 웹 애플리케이션
  5. 승인된 자바스크립트 원본에 이 앱 주소의 도메인 추가 (예: https://내아이디.github.io, 뒤에 경로·슬래시 없이)
  6. 발급된 클라이언트 ID를 아래에 붙여넣기
유튜브 앱에서 열기 사파리에서 열기

검색 1회 = 쿼터 100, 재생목록 생성 1회 + 곡 추가 1곡당 각 50이 들어가요. 하루 한도는 10,000이라 한 번에 20~30곡씩, 하루 서너 번 정도 쓰면 돼요. 한 번 찾은 곡은 폰에 저장돼서 다시 안 깎여요.
